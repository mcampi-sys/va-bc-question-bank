# VA-BC Question Bank

Miguel's VA-BC practice questions — every question is multiple choice, with the rationale shown right after you answer. Question order and answer choices are randomized on every open.

**Open the app:** https://mcampi-sys.github.io/va-bc-question-bank/

On your phone: open that link in Chrome, tap the menu (three dots), then **Add to Home screen** — it gets its own icon and opens full-screen like an app.

This site updates automatically as new study questions are added. To download the app as a single file instead, open `index.html` above and use the download button.
